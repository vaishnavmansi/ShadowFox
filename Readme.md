# 🧮 Calculator Project (Java Swing GUI)

## 📌 Overview
This is a Java-based Graphical User Interface (GUI) Calculator built using Swing.  
It performs basic arithmetic operations and also includes currency and temperature conversions.

---

## ✨ Features

### ➕ Basic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

### 🔢 Advanced Functions
- Square Root (√)
- USD → INR conversion
- INR → USD conversion
- Celsius → Fahrenheit
- Fahrenheit → Celsius

---

## 🖥️ GUI Components Used
- JFrame → Main window
- JPanel → Layout sections
- JTextField → Input fields
- JLabel → Result display
- JButton → Operation buttons
- GridLayout → Button arrangement

---

## ⚙️ How It Works
1. Enter number(s) in input fields
2. Click any operation button
3. Result is displayed at the bottom

Operations include:
- +, -, *, /
- Sqrt
- USD ↔ INR
- Celsius ↔ Fahrenheit
